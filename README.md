# LilyPond Zed Extension

This [Zed](https://zed.dev) extension adds syntax highlighting for [LilyPond](https://lilypond.org).

<img width="1084" alt="Screenshot of LilyPond Zed extension using the Catppuccin Macchiato theme and the Zed Mono font" src="https://github.com/user-attachments/assets/70219159-74f3-4f77-bdcb-b0f9af22efc5">

> [!NOTE]  
> Syntax highlighting provided by v0.0.9 (and earlier) of this extension is effectively broken in Zed [v0.231.0](https://github.com/zed-industries/zed/releases/tag/v0.231.0-pre) and later due to https://github.com/zed-industries/zed/pull/52183. A [pull request to address this](https://github.com/zed-industries/extensions/pull/5884) has been open since May 2026. Until that pull request is merged, you can use this extension by cloning it—
> ```sh
> git clone https://github.com/nwhetsell/lilypond-zed-extension
> ```
> —and then [installing it as a dev extension](https://zed.dev/docs/extensions/developing-extensions#developing-an-extension-locally).
